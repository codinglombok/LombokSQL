# Vectors

`lomboksql-vectors-v1.json` is the cross-language test contract for LombokSQL.

- SHA-256: `39142d61f40466dc6afa4d312215ab2ea1dc59c432a8c78bcb61f51d75ef4164` (must equal the hash in `docs/SPEC_LombokSQL_v0.1.0.md`).
- Generated by `scripts/gen-vectors.mjs`. Group `golden`: the PostgreSQL expectation is written by hand, the other dialects are derived by a string transform, and syntax that differs is written by hand. Group `generated-regression`: expectations come from the TypeScript compiler and are confirmed by the Rust port.
- Every claimed port MUST run every case.
